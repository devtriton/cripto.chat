Guia Educacional: Fundamentos da Criptografia

1. O que é Criptografia?

Criptografia é o processo de transformar uma mensagem legível (texto claro) em uma mensagem ilegível (texto cifrado), de modo que apenas quem possui a chave correta possa reverter o processo.

2. Criptografia Simétrica

Neste projeto, usamos criptografia simétrica: a mesma chave é usada para criptografar e descriptografar. Isso significa que o remetente e o destinatário precisam compartilhar a mesma chave.

3. Algoritmos Implementados

  • Cifra de César: Desloca cada letra por N posições no alfabeto. Simples, mas vulnerável.
  • Cifra de Vigenère: Usa uma palavra-chave para variar o deslocamento. Mais segura que César.
  • XOR: Operação bit a bit com chave. Base para muitos sistemas modernos.
  • AES-256: Padrão avançado. Usado em sistemas reais de segurança.

4. A Sala ADM

A Sala ADM representa o ponto de vista do servidor. Tudo que passa pelo servidor é visível aqui.

  • Sem criptografia: O servidor vê a mensagem em texto claro (verde na ADM).
  • Com criptografia: O servidor vê apenas o texto cifrado (vermelho na ADM).

5. Conceitos Importantes

  • Texto Claro (Plaintext): Mensagem original, legível.
  • Texto Cifrado (Ciphertext): Mensagem após criptografia, ilegível.
  • Chave: Segredo usado para criptografar/descriptografar.
  • Ataque de Força Bruta: Tentar todas as chaves possíveis.
